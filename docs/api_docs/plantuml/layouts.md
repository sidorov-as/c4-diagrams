# PlantUML Layouts

PlantUML layout helpers live in `c4.contrib.plantuml` and render as
C4-PlantUML `Lay_*` macros.

::: c4.contrib.plantuml.Layout
    options:
        show_root_heading: true
        merge_init_into_class: false
        group_by_category: false
        inherited_members: true
        show_source: false
        members:
          - __init__
