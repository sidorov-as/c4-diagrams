# Supporting Diagrams

The C4 model also includes supporting views that answer questions beyond the
basic static zoom levels:

- [System landscape](system-landscape.md): how multiple systems fit together
  across an enterprise, department, or portfolio.
- [Dynamic](dynamic.md): how elements collaborate at runtime for a feature,
  use case, or scenario.
- [Deployment](deployment.md): how software maps onto infrastructure in a
  specific environment.

Each page documents the model purpose, supported DSL classes, portable examples,
backend-specific behavior, and generated output.
